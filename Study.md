> [!tip] Make the AI test you
> Reading an explanation feels like learning. Answering questions is what makes it stick.

## Prompt: explain like a beginner
```text
Explain [topic] as if I've never heard of it. Use a simple real-life
example, define every technical word, and end with 3 key points.
```

## Prompt: quiz me
```text
Quiz me on [topic] with 5 questions, one at a time, from easy to hard.
Wait for my answer, tell me if I'm right, explain, then ask the next one.
```

## Prompt: summarize my notes
```text
Summarize these notes: [paste].
Output: a 5-bullet summary, a list of key terms with definitions,
and 3 questions I should be able to answer after studying.
```

## Prompt: check my understanding
```text
I'll explain [topic] in my own words. Point out what I got wrong or
missed, then explain the correct version simply.
My explanation: [write it]
```

## Prompt: study plan
```text
Context: I have [time] before [exam/deadline]. Topics: [list].
My level: [beginner/okay/strong] in each.
Goal: [e.g., pass the exam]
Make a day-by-day plan. Acceptance criteria:
- [ ] Each day has a clear task and a time limit
- [ ] Hardest topics come early
- [ ] Includes review and practice-quiz days
```
